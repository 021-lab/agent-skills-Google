# CryptoPrices — замена формулы на CryptoCompare

Старая формула в Google Таблицах:

```
=if(I1=1, ImportJSON("https://min-api.cryptocompare.com/data/price?fsym=USD&tsyms="&G2&"&api_key=...", "/"))
```

перестала работать (эндпоинт/ключ CryptoCompare отвалился). Этот проект —
точный аналог той же формулы, но на **CoinGecko** — бесплатном публичном
API без ключа для нужного нам эндпоинта (`/simple/price`), с высокой
доступностью и без внешних зависимостей типа стороннего `ImportJSON`.

## Что внутри

- `CryptoPrices.gs` — код Google Apps Script с кастомными функциями
  для использования прямо в ячейках таблицы.
- `appsscript.json` — манифест Apps Script проекта.

## Функции

### `CRYPTOCOMPARE_PRICE(tsyms, [fsym])`

Точный аналог старой формулы. `tsyms` — список тикеров через запятую
(например значение из `G2`: `"BTC,ETH,SOL"`), `fsym` — базовая валюта,
по умолчанию `"USD"`. Возвращает **ту же величину**, что раньше отдавал
CryptoCompare для `fsym=USD&tsyms=...` — то есть сколько единиц каждого
тикера эквивалентно 1 единице `fsym` (обратный курс).

Использование (замена старой ячейки):

```
=IF(I1=1, CRYPTOCOMPARE_PRICE(G2))
```

или с другой базовой валютой:

```
=IF(I1=1, CRYPTOCOMPARE_PRICE(G2, "EUR"))
```

Результат — одна строка значений, которая «растекается» по столбцам
вправо, как это делал `ImportJSON`, в том же порядке, что и тикеры в `G2`.
Тикеры, которые не удалось распознать или получить по ним цену,
возвращаются как `#N/A`.

### `CRYPTO_PRICE(tsyms, [fsym])`

Бонус-функция для более привычного случая — прямой курс (сколько `fsym`
стоит один тикер), например сколько USD стоит 1 BTC. В исходной формуле
такого не было, но оставлена для удобства, если понадобится.

```
=CRYPTO_PRICE(G2)
=CRYPTO_PRICE(G2, "EUR")
```

## Установка в Google Таблицы

1. Открыть таблицу → **Расширения → Apps Script**.
2. Скопировать содержимое `CryptoPrices.gs` в редактор скриптов
   (файл `Код.gs` / `Code.gs`).
3. Сохранить проект.
4. Вернуться в таблицу и заменить старую формулу с `ImportJSON(...)`
   на `CRYPTOCOMPARE_PRICE(...)`, как показано выше.

Ключ API не нужен — CoinGecko отдаёт цены по `/simple/price` публично.
Единственное ограничение — общий лимит запросов бесплатного API
CoinGecko (это влияет только на скорость обновления при очень частых
пересчётах, а не на корректность значений).

## Как это устроено

- Тикеры (`BTC`, `ETH`, ...) переводятся в идентификаторы CoinGecko
  (`bitcoin`, `ethereum`, ...) через встроенную карту частых монет и,
  если тикер в неё не попал, через полный список `/coins/list`,
  закешированный в `CacheService` на 6 часов.
- Курс запрашивается одним запросом `/simple/price` на все тикеры сразу
  (как и раньше делал CryptoCompare), а не по одному запросу на тикер.
- Ошибки сети/API выбрасываются с понятным текстом вместо тихого
  `#ERROR!`, а нераспознанные тикеры дают `#N/A` в соответствующей
  ячейке, не ломая остальную строку.
