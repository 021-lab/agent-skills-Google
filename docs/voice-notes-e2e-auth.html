Voice Notes E2E Auth Helper

This helper computes the stable Firebase Hosting URL used by the real Drive/Gemini smoke test and shows the two local commands needed to save and upload the signed-in browser session.

Stable sign-in URL

Fill in a Firebase project id

Use the allowlisted Google account on this exact URL.

1. Save the browser session locally 
FIREBASE_PROJECT_ID=<project-id> npm run e2e:auth:save

This opens Chromium, waits for a real sign-in, then writes playwright/.auth/voice-notes-google.json.

2. Upload the saved session into GitHub Actions 
npm run e2e:auth:upload-secret

This updates the GitHub secret E2E_PLAYWRIGHT_STORAGE_STATE_B64.

Where things go
  • Local session file: playwright/.auth/voice-notes-google.json
  • GitHub Actions secret: E2E_PLAYWRIGHT_STORAGE_STATE_B64
  • Allowlisted email secret already used by CI: E2E_GOOGLE_EMAIL
